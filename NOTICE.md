# Source and rights notice

This repository is a patch-only source kit. It does not contain a complete
copy of reVC. The supported upstream input is the exact public reVC commit
recorded in `patch-manifest.json`; that project retains its own terms and
notices.

The root `LICENSE` applies only to original Vice City VR contributions. Patch
context copied from upstream files is not relicensed by this kit.

The complete `librw/` source snapshot is included under its own MIT license at
`librw/LICENSE`. Other external SDKs and runtime components, including OpenXR,
NVIDIA Streamline/DLSS, FidelityFX FSR 2, OpenAL Soft, and mpg123, are not
included and retain their own terms.

The generic model-set utilities under `tools/modelsets/` retain the separate
scope stated in `tools/modelsets/TOOL_NOTICE.md`. Optional third-party model
packs and the pack-specific downloader are deliberately not part of this kit.

No Grand Theft Auto: Vice City executable, game data, localization, models,
textures, audio, keys, or proprietary runtime binaries are included. Users
must supply a legally obtained game installation and required SDKs locally.
